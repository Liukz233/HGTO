# Recorded paper results

These compact tables contain the selected results reported in the supplied
HGTO manuscript. They are comparison targets, not results generated by the
current checkout. Times reflect the paper's stated hardware and measurement
intervals. `linear.csv` maps cases to the current configuration paths.

The nonlinear cantilever CSV's `status=completed` means a final state was
written; strong-load OC nevertheless stalled. Use the paper and run termination
metadata when distinguishing completed output from convergence. NTopo's
strong-load failure has no final objective or complete-design time.

The plastic response values compare both designs under the same elastoplastic
loading history. Residual displacement is not the optimization objective.
