# Recorded paper results

These compact tables contain the results reported in the HGTO manuscript, at
full precision from the run records. They are comparison targets, not results
generated by the current checkout. Times reflect the paper's stated hardware
and measurement intervals. Both files map cases to the current configuration
paths.

`linear.csv` lists compliance, achieved volume, total time and termination for
the linear examples (Tables 4 and B.1 of the paper).

`nonlinear.csv` lists the finite-deformation examples (Tables 5 and D.2): the
objective `J` (twice the complementary work), total time, design updates,
Newton iterations of all completed state solves, updates that fell back from
the continued state to incremental loading, rejected trial steps, achieved
volume and termination. SIMP--OC ran on two CPU threads with PARDISO, HGTO on
the GPU with cuDSS; both continue the state between design updates. NTopo
rows use the nonlinear adaptation and report its budget endpoint; the strong
cantilever and bridge runs stopped during state training and have no
completed-design metric.
